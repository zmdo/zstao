# 提示词

可复用的提示词，一个文件一个用途。用法：复制文件内容，替换 `{{变量}}`，把产物贴回工作项。

| 提示词 | 用途 | 输入 | 输出 |
| --- | --- | --- | --- |
| [spec-writer.md](spec-writer.md) | 把想法写成可验收的规格 | 想法、背景、约束 | 规格文档 |
| [code-review.md](code-review.md) | 对一次改动做结构化评审 | diff、业务背景 | 结论 + 阻塞项 / 建议 / 疑问 |
| [debug.md](debug.md) | 系统化定位缺陷 | 现象、复现步骤、日志 | 根因假设 + 验证步骤 |
| [daily-review.md](daily-review.md) | 日终复盘，产出明天第一件事 | 当日工作项、提交 | 复盘 + 明日计划 |

## 使用约定

- 替换所有 `{{变量}}`，缺失的写「未知」，不要留占位符。
- 输出不符合【验收】就重跑，不要手工修补 AI 的结论。
- 高频调整的同一条提示词，改回这里，不要在对话里临时改。

## 新增提示词

1. 复制 [`daily-review.md`](daily-review.md) 的结构（用途 / 变量 / 提示词 / 验收）。
2. 文件名用 `kebab-case`，与用途一致。
3. 在本文件索引里登记。
4. 运行 `powershell -File scripts/Test-Repo.ps1` 确认索引完整。
