# 工作区目录选择器（Finder 风格）设计

- 状态：方案设计，待评审
- 日期：2026-11-04
- 分支：`dev/0.0.1-alpha`
- 范围：`@smp/console-workspace-groups` 的“选择工作区目录”弹窗
- 目标：用接近 macOS 文件选择器的列视图替换当前树形弹窗，同时保留 CES 现有按钮和主题风格

## 1. 背景

当前实现已经能在两个入口打开自定义目录选择器：

- 对话框上方“添加工作区…”
- 侧边栏“添加工作区”

但视觉上仍是自制的“左侧树 + 右侧列表”，与 macOS 文件选择器差距较大。新的设计要求：

1. 主区域采用 macOS Finder 的**列视图**，而不是独立的左树 + 右列表。
2. 最左侧灰色侧边栏改成**工作区组列表**，只展示普通组，排除“未归属”。
3. 按钮、输入框、颜色和状态使用 CES 现有设计系统，不直接复制 macOS 控件。
4. 打开时，从当前工作区组“默认工作区”的父目录开始。

## 2. 目标与非目标

### 目标

- 更接近 macOS 文件选择器的信息密度和浏览方式。
- 左侧切换工作区组，右侧浏览该组目录。
- 顶部路径导航、底部操作按钮保持不变的心智。
- 不改后端目录 API、不改工作区创建/归属逻辑。
- 支持懒加载，避免打开时递归扫描整个工作区。

### 非目标

- 不实现 macOS 的“最近使用”“共享”“标签”“iCloud”等系统位置。
- 不实现 Finder 的图标视图、分栏/全屏、拖拽移动、文件预览。
- 不实现跨工作区组的目录选择。
- 不修改 DSH 的 workspace picker、directory flow 协议或数据库结构。

## 3. 布局

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 选择工作区目录                                                ×     │
├──────────────┬──────────────────────────────────────────────────────┤
│ 工作区组      │  [←] [→]   /srv/workspaces/.smp/workspaces           │
│              ├───────────────┬────────────────┬────────────────────┤
│ ● 默认组      │ workspaces    │ default-workspace │                  │
│ ○ 服务器运维  │ ▸ releases    │ ▸ assets       │                  │
│              │ ▸ tmp         │                │                  │
│              │               │                │                  │
├──────────────┴───────────────┴────────────────┴────────────────────┤
│ [新建文件夹]                                      [取消] [选择]   │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.1 左侧工作区组栏

- 宽度约 `200–220px`，浅灰背景，和 macOS 侧边栏的层次接近。
- **贯通整个弹窗高度**：从弹窗顶部一直到弹窗底部，不被标题栏或底部操作栏截断；标题、工具栏、列视图和底栏都只位于右侧主区域。
- 只渲染 `kind === 'normal'` 的工作区组。
- 明确排除 `unassigned`（未归属）。
- 每行包含：
  - 文件夹图标
  - 工作区组名称（使用现有 `labelI18n`/locale）
  - 选中态高亮
  - 可选：默认工作区路径作为 `title`，不占用行内空间
- 顶部标题：`工作区组` / `Workspace groups`
- 当前组变化时：
  - 重置列视图到该组的起始目录
  - 清空历史栈、列缓存、错误状态
  - 不保留上一个组的选中目录，避免误选

### 3.2 顶部工具栏

- 左侧：后退/前进按钮，使用当前 console 按钮样式。
- 中间：当前路径，可直接点击面包屑回退；保留完整路径的可读性。
- 右侧：可选的“显示隐藏文件”开关；第一版可以先不做搜索。
- 路径过长时横向滚动，不换行。

### 3.3 主区域：Finder 列视图

采用 macOS 文件选择器的 Miller columns：

```text
[组根目录] → [子目录] → [孙目录] → ...
```

- 打开时第一列是当前工作区组的起始目录。
- 点击某一列中的文件夹：
  - 该列右侧生成/替换下一列
  - 当前目录更新为该文件夹
  - 顶部路径同步
- 点击当前列中已选中的文件夹：进入下一列。
- 点击列中空白处：选中该列目录，不继续深入。
- 列的宽度：约 `240–280px`，可横向滚动。
- 行高、选中底色、文件夹图标使用 CES token，不照搬 macOS 蓝色选中。
- 目录为空时显示“这个目录下没有子目录”。
- 加载中在列内显示骨架/文字，不阻塞其他列。

### 3.4 底部操作栏

- 左侧：`新建文件夹`
- 右侧：
  - `取消`
  - `选择当前目录`（主按钮，沿用现有样式）
- 当前绝对路径只放在顶部面包屑，不在底栏重复；底栏用左右两组分开，避免路径挤压按钮。
- 新建文件夹：
  - 在当前列底部出现内联输入框
  - Enter 创建，Escape 取消
  - 成功后刷新当前列并选中新目录
- 选择当前目录：
  - 使用当前列对应的目录
  - 若当前列尚未加载完成则禁用
  - 仍然走现有 `createWorkspace({ path })` / `onPicked` 流程

## 4. 起始目录

对每个工作区组独立计算：

```text
defaultMember = members.find(m => m.groupId === groupId && m.isDefault)
start = defaultMember ? dirname(defaultMember.directory) : group.path
```

当前部署下：

```text
默认组：/srv/workspaces/.smp/workspaces
服务器运维：/srv/workspaces/.smp/server-ops-workspaces
```

规则：

- 默认工作区在更深的目录时，以它真实的父目录为准，不写死组路径。
- 没有默认工作区时回退到 `group.path`。
- 切换组时重新计算，不复用上一组的目录。
- 选择范围限制在该组的起始目录子树内；面包屑不展示起始目录之上的父级，防止误选到组外。

## 5. 状态模型

```ts
type PickerState = {
  groupId: string
  root: string
  current: string
  columns: Array<{
    path: string
    listing?: DirectoryListing
    selected?: string
    loading: boolean
    error?: string
  }>
  history: string[]
  historyIndex: number
  showHidden: boolean
  creating: boolean
  newName: string
}
```

- 每一列拥有独立的 `listing` 和错误状态。
- `current` 始终等于最后一列的 `path`。
- 点击历史/面包屑时截断列到目标路径。
- 列缓存以绝对路径为 key，避免重复 `listDirectory`。
- 所有异步请求使用 `AbortController`；切组、关闭弹窗、快速点击时取消旧请求。

## 6. 交互细节

### 鼠标

- 单击目录行：选中并进入下一列。
- 单击已选中行：进入下一列（Mac 双击的轻量替代）。
- 单击列空白：该列成为当前目录，不深入。
- 顶部面包屑：回退到对应列。
- 侧栏组：切换根目录。
- 遮罩点击：取消。
- 底部按钮：新建、取消、选择。

### 键盘

- `↑/↓`：当前列上下移动。
- `→` / `Enter`：进入选中目录。
- `←` / `Backspace`：回到上一列。
- `Escape`：取消。
- `Cmd/Ctrl + Shift + N`：新建文件夹。
- 输入框内不拦截全局快捷键。

### 错误

- 读取失败：只影响当前列，显示错误和“重试”按钮。
- 创建失败：保留输入框，显示后端业务错误。
- 权限不足/目录不存在：不关闭弹窗。
- 组不可用：显示空状态，不退回原生弹窗。

## 7. 数据与接口

复用现有客户端能力，不新增后端接口：

- `uiWorkspace.listDirectory(path, signal)` → `DirectoryListing`
- `uiWorkspace.createDirectory(path, name)` → 新目录路径
- `createWorkspace({ path })` / `onPicked` → 现有工作区创建/选择
- `GroupSnapshot.groups` / `members` → 组列表、默认工作区、起始目录

`DirectoryListing` 已包含：

- `path`
- `parent`
- `entries`（名称、路径、hidden）
- `crumbs`

因此列视图和面包屑不需要额外 host API。

## 8. 视觉规范

### 布局尺寸

- 弹窗：`min(1040px, 92vw)` × `min(640px, 86vh)`
- 侧栏：`210px`
- 顶栏：`44px`
- 底栏：`52px`
- 列宽：`248px`
- 列视图容器使用 `bg-module-platform` 浅灰，单列使用 `layer-1` 白底，列间保留分隔线，避免多列连成一片
- 侧栏与列视图之间使用 `border-l3` 分隔线，列与列之间使用 `border-l2` 分隔线
- 行高：`32px`
- 圆角：`10–12px`
- 阴影：轻量浮层阴影，不使用 macOS 窗口交通灯

### 颜色

- 弹窗背景：`var(--dsw-alias-bg-layer-1)`
- 侧栏：`var(--dsw-alias-bg-module-platform, #f5f6f7)`，比主区域更深一层
- 分隔线：`var(--line)`
- 选中行：`var(--dsw-alias-interactive-bg-selected, rgb(37 99 235 / 12%))`
- 主按钮：`var(--accent, #2563eb)`
- 文本：`var(--dsw-alias-label-primary)` / `var(--muted)`

### 图标

- 使用内联 SVG 文件夹/箭头，不使用 emoji 或 `▱`。
- 侧栏组图标与目录图标区分。
- 隐藏文件默认不显示；开关打开后以降低透明度展示。

### 响应式

- 宽度 `<720px`：
  - 侧栏改为顶部横向组标签
  - 列视图保留横向滚动
  - 底栏按钮换行或压缩
- 高度不足时列区域独立滚动，头尾固定。

## 9. 组件拆分

```text
DirectoryPicker
├─ GroupRail          工作区组列表（排除 unassigned）
├─ PickerToolbar      后退/前进、路径、隐藏文件开关
├─ ColumnView         列视图容器
│  └─ DirectoryColumn 单列：加载、空态、错误、行
├─ PickerFooter       路径、新建文件夹、取消、选择
└─ NewFolderInput     内联新建
```

`DirectoryPicker` 保留现有 `open`、`busy`、`onPicked`、`onCancel`、`onError` 协议；`Picker.tsx` 继续只负责 slot 注册和 native workspace picker 的委托。

## 10. 实施顺序

### P1：视觉与主流程

- 组侧栏（排除 unassigned）
- 列视图、路径栏、底栏
- 起始目录按组计算
- 选择当前目录、取消
- 加载/空/错误状态

### P2：交互完善

- 后退/前进历史
- 新建文件夹
- 键盘导航
- 隐藏文件开关
- 宽度响应式

### P3：性能与细节

- 列缓存与请求取消
- 大目录虚拟滚动
- 路径超长处理
- 组切换动画/焦点管理

## 11. 验收标准

1. 默认组打开时起始目录是 `/srv/workspaces/.smp/workspaces`。
2. 服务器运维组打开时起始目录是 `/srv/workspaces/.smp/server-ops-workspaces`。
3. 左侧只出现普通工作区组，不出现“未归属”。
4. 点击组只切换该组目录，不串组。
5. 列视图可逐级进入、面包屑可回退。
6. 新建文件夹成功后当前列刷新。
7. 选择当前目录后仍走现有工作区创建/选择逻辑。
8. 取消、遮罩、Escape 行为一致。
9. 窄屏下仍可操作。
10. 不出现原生 DSH 目录弹窗。

## 12. 风险

| 风险 | 应对 |
| --- | --- |
| 列视图在深层目录下横向过长 | 列宽固定、横向滚动、当前列自动滚入视野 |
| 组切换时旧请求返回覆盖新状态 | 每次切组/关闭取消请求，校验 groupId + requestId |
| 目录很多导致卡顿 | 懒加载、按需列、P3 虚拟滚动 |
| 误选到组外目录 | 面包屑只展示起始目录以下，列导航限制在 root 子树 |
| 视觉像 macOS 但和 CES 冲突 | 结构借鉴 Finder，颜色/按钮/字体继续用 CES token |
| 原生侧边栏 flow 抢回 | 继续使用 `priority: -100` 覆盖 native flow，并保留回归测试 |
